## 🚀 Быстрый старт

### Интерактивный режим (рекомендуется для новичков)

Просто запустите скрипт без параметров:

```bash
python "ticket generator.py"
```

Программа пошагово проведет вас через процесс:
1. Запросит путь к папке с файлами
2. Предложит выбрать язык (узбекский/русский)
3. Автоматически создаст билеты

### Командная строка (для продвинутых пользователей)

```bash
# Узбекские билеты (360 штук)
python "ticket generator.py" -l uzbek -t 360 -p ./путь/к/папке

# Русские билеты (160 штук)
python "ticket generator.py" -l russian -t 160 -p ./путь/к/папке
```

## 📖 Использование

### Параметры командной строки

| Параметр | Короткий | Описание | По умолчанию |
|----------|----------|----------|--------------|
| `--path` | `-p` | Путь к папке с файлами вопросов | Текущая папка |
| `--tickets` | `-t` | Количество билетов для генерации | 360 |
| `--language` | `-l` | Язык билетов: `uzbek` или `russian` | `uzbek` |
| `--output` | `-o` | Имя выходного файла | Автоматически |
| `--help` | `-h` | Показать справку | - |

### Формат входных файлов

Программа работает с Word документами (.docx), содержащими таблицы с вопросами.

**Структура таблицы:**
```
| № | Вопрос                    |
|---|---------------------------|
| 1 | Текст первого вопроса     |
| 2 | Текст второго вопроса     |
| 3 | ...                       |
```

**Важно:**
- Файлы должны быть в формате `.docx` (не `.doc`!)
- Таблица должна иметь минимум 2 колонки
- Первая колонка - номер, вторая - текст вопроса

## 🔧 Устранение проблем

### ❌ "ModuleNotFoundError: No module named 'docx'"

**Решение:**
```bash
pip install python-docx
```

### ❌ "Файл не найден"

**Возможные причины:**
1. Неправильное название файла
2. Файл находится не в указанной папке
3. Неверно указан путь к папке

**Решение:**
- Проверьте точность названий файлов (включая пробелы и регистр)
- Убедитесь, что все файлы находятся в одной папке
- Используйте абсолютный путь для надежности

### ❌ "Не удалось извлечь вопросы"

**Возможные причины:**
1. Файл в старом формате `.doc` вместо `.docx`
2. Вопросы не в таблице
3. Неправильная структура таблицы

**Решение:**
- Конвертируйте `.doc` файлы в `.docx`
- Убедитесь, что вопросы находятся в таблице
- Проверьте, что таблица имеет минимум 2 колонки

### ⚠️ Мало вопросов в одном предмете

**Это нормально!** Программа автоматически повторит вопросы при необходимости. Система умно распределяет вопросы по циклам для обеспечения достаточного количества билетов.

## 💻 API для разработчиков

Вы можете использовать класс `TicketGenerator` в своих Python скриптах:

```python
from ticket_generator import TicketGenerator

# Создаем генератор
generator = TicketGenerator("/путь/к/папке/с/файлами")

# Настраиваем файлы и названия
subject_files = {
    'literatura': 'Адабиёт рус савол.docx',
    'vospitanie': 'Тарбия рус савол.docx',
    'istoriya': 'Тарих рус савол.docx'
}

subject_names = {
    'literatura': 'ЛИТЕРАТУРА',
    'vospitanie': 'ВОСПИТАНИЕ',
    'istoriya': 'ИСТОРИЯ'
}

# Создаем билеты
tickets = generator.create_tickets(subject_files, subject_names, 160)

# Сохраняем
generator.save_tickets(tickets, subject_names, "билеты.docx")
```

Чтобы изменить количество билетов на странице, отредактируйте строку 138 в `ticket generator.py`:

if (i + 1) % 3 == 0:  # Измените 3 на нужное число
    doc.add_page_break()
